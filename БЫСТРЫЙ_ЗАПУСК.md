# 🚀 Быстрый запуск CoffeeOk в симуляторе

## Самый простой способ:

### 1. Двойной клик
Просто **дважды кликните** на файл `CoffeeOk.xcodeproj` в Finder

### 2. Или через терминал:
```bash
open CoffeeOk.xcodeproj
```

### 3. Или используйте скрипт:
```bash
./запустить.sh
```

---

## После открытия в Xcode:

1. **Выберите симулятор** в верхней панели (например, iPhone 15 Pro)
2. **Нажмите ⌘R** (Command + R) или кнопку ▶️ Play
3. **Готово!** Приложение запустится в симуляторе

---

## Если проект не открывается:

### Вариант 1: Создать новый проект в Xcode
1. Откройте Xcode
2. **File → New → Project**
3. Выберите **iOS → App**
4. Название: `CoffeeOk`
5. Interface: **SwiftUI**
6. Language: **Swift**
7. Скопируйте все файлы из папки `CoffeeOk/` в новый проект

### Вариант 2: Использовать Xcode для исправления
1. Откройте Xcode
2. **File → Open Recent → CoffeeOk.xcodeproj**
3. Если появится ошибка, Xcode может предложить исправить проект автоматически

---

## Альтернативный способ - через командную строку:

```bash
# Открыть проект
open CoffeeOk.xcodeproj

# Или собрать и запустить напрямую (если проект исправлен)
xcodebuild -project CoffeeOk.xcodeproj -scheme CoffeeOk -destination 'platform=iOS Simulator,name=iPhone 15 Pro' build
```

---

## Полезные команды:

- **⌘R** - Запустить приложение
- **⌘.** - Остановить приложение  
- **⌘B** - Собрать проект
- **⌘ShiftK** - Очистить сборку

---

## Требования:

- ✅ Xcode 15.0+ (у вас установлен Xcode 26.2)
- ✅ iOS 17.0+ симулятор
- ✅ macOS 14.0+

---

**Примечание:** Если проект все еще не открывается, лучше создать новый проект в Xcode и скопировать туда файлы из папки `CoffeeOk/`.
